What do you need help with?

Type a request the way you'd say it to a colleague. This replaces browsing a 100+ item service catalog by hand - the model reads your text and routes it to the right catalog item, live, in your browser.

Running entirely client-side on exported TF-IDF + logistic regression weights (the same model served in production). The full system also includes a from-scratch multi-task neural network, a FastAPI backend with an active-learning feedback loop, and a data-versioned retraining pipeline - see the repo README.
