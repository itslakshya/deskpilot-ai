# Dataset changelog

## v1 - initial synthetic dataset
- Generated by `src/generate_dataset.py`: 6,371 rows, 19 catalog categories, 4 priority levels
- ~4.5% simulated label noise on confusable category pairs; priority labels include
  deliberate stochasticity (category base-rate + requester seniority + department)

## v2 - 2026-09-09T14:49:25+00:00 (pipeline demonstration run)
- Added 15 candidate rows from `new_tickets_test.csv` (1 rejected by schema validation, 0 deduped)
- Total dataset size: 6371 -> 6386
- This run was a one-time demonstration that `scripts/append_and_retrain.py` works end to
  end (validation, versioning, retraining, champion/challenger gating all exercised). The
  production models in `models/` and the metrics in `README.md` are pinned to **v1** - v2
  was not promoted as the working dataset, just kept as evidence the pipeline runs cleanly.
